Skill Builder in Markdown

Trasforma una procedura di lavoro in un file SKILL.md. Compila, osserva il Markdown, controlla e scarica. Senza programmare.

✓ Dati fittizi✓ Senza account✓ Nessun invio di dati✓ Funziona anche offline
Da dove veniamo? Nella libreria salvavamo un prompt da cercare, copiare e adattare. Qui descriviamo un metodo riutilizzabile in un formato che alcuni ambienti AI possono riconoscere come skill. Il file non esegue azioni da solo.
1Scegli un caso→2Descrivi il metodo→3Scarica la skill

Costruiamo la skill

Ogni campo diventerà una parte del file Markdown, visibile a destra.

1Scegli il punto di partenza
2Scrivi le istruzioni

Minuscole e trattini, senza spazi. Diventerà il nome della cartella ZIP.

È il campo più importante per capire in quali situazioni richiamare la skill.

Una riga = una voce dell'elenco.

Una riga = un passaggio numerato. La skill descrive il metodo, non lo esegue in questa pagina.

Includi cosa non fare: non inventare informazioni, non assumere decisioni e non inviare nulla.

Ricorda: una skill rende più coerente un metodo. Non garantisce un risultato corretto, non attribuisce permessi e non sostituisce la valutazione del funzionario.

    La prova individuale · 10 minuti
    1. Scegli Sintesi di segnalazione e leggi il file generato.
    2. Modifica la descrizione: deve spiegare quando usare la skill.
    3. Aggiungi un controllo alla procedura o alle regole e limiti.
    4. Apri Come si legge, poi scarica SKILL.md e lo ZIP.
    La domanda finale: rispetto al prompt conservato in libreria, quali istruzioni non dovrai più riscrivere? E chi dovrà comunque verificare il risultato?
    
    
    Prova facoltativa in una chat AI
    È una simulazione manuale del metodo: non installa una skill nativa.
    Se usi una chat esterna, incolla soltanto il caso fittizio. Il sistema potrebbe non riconoscere automaticamente il file come skill nativa.
    Perimetro PA: nessun dato reale, nessuna connessione al protocollo o ai gestionali, nessuna firma o invio automatico. Il risultato resta una BOZZA da verificare.
